# Contributing

Thank you for your interest in StellarForge.

## Getting Started

1. Fork the repository.
2. Clone locally.
3. Install dependencies.
4. Create a feature branch.
5. Open a Pull Request.

## Development Workflow

- Pick an assigned issue.
- Follow coding standards.
- Write tests.
- Update documentation.
- Ensure CI passes.

## Pull Requests

Every PR should:

- Reference an issue
- Include tests when applicable
- Pass linting
- Update docs if necessary

## Good First Issues

Look for the label:

good first issue

Happy building 🚀
